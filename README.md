## Функциональность «Отзывы» (Ф‑1)

Добавлена функциональность отзывов (reviews) с поддержкой лайков и дизлайков.

**Что реализовано:**

* CRUD‑операции для отзывов (создание, обновление, удаление, получение);
* добавление и удаление реакций (лайк / дизлайк);
* пересчёт рейтинга полезности ($\text{useful} =$ сумма реакций);
* сортировка отзывов по полезности (`ORDER BY useful DESC`);
* поддержка получения отзывов:
    * всех отзывов;
    * отзывов по конкретному фильму;
* ограничение количества отзывов (`limit`).

**База данных:**

* добавлены таблицы `reviews` и `review_reaction`;
* настроены внешние ключи и каскадное удаление;
* обновлён `schema.sql`.

**Тестирование:**

* реализованы интеграционные тесты `ReviewRepositoryTest`;
* реализованы тесты бизнес‑логики `ReviewServiceTest`;
* проверены сценарии:
    * создание, обновление, удаление отзывов;
    * добавление / удаление лайков и дизлайков;
    * замена реакции;
    * корректный пересчёт `useful`;
    * обработка ошибок (пользователь / фильм / отзыв не найден).

**Прочее:**

* методы реакций переведены с `boolean` на `void`.
